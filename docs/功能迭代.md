## 当前顺序

1. 导出阻塞优先：先确认输入文件与目标格式，再修对应处理路径。区分输入解码、像素编辑、输出编码的峰值；JPEG 分条编辑与 HEIF 网格编码分别计算缓存和工作区，不用直接放宽预算代替处理能力。
2. 风格收敛：寒峻先保留当前效果供后续复测；冷钢、暗红、灰烬作为独立试用配方落地，原有滤镜保留作对照，不同时改动通用管线。
3. 边框及编辑体验修复：以用户复测问题为准，避免同时扩张模板和交互。
4. 平台验证和分发按工具链条件安排，不阻塞桌面核心问题定位。

## 状态规则

- 计划：有目标及完成依据，尚未实现。
- 已接入 / 待验证：源码已连接，尚无本轮运行结果。
- 验证通过：记录命令、平台、版本及结果。
- 效果确认：用户对具体滤镜或体验确认。

每轮只推进明确范围；滤镜清单记录配方变化，功能迭代记录管线与交互任务，验证记录只记录实际发生的检查。本轮测试仍由用户执行。

## 相框类型与模板（2026-10-21）

编辑入口由「边框」改为「相框」，分为留白、摄影、胶片、社交卡片；每类显示独立设置。摄影保留原有品牌、镜头、EXIF 与高级排版。留白仅显示宽度与颜色。

- 胶片：两侧或上下齿孔，可关闭齿孔，编辑胶片文字、帧编号及日期附注；黑色底片与琥珀色文字。
- 社交卡片：Instagram、Facebook、X、微信朋友圈四套固定排版；单张照片保持原比例，头像、昵称、账号、地点、配文、时间及互动文字可编辑，头像和互动栏可隐藏。配文自动换行并支持手动分段；清空字段会隐藏内容。
- 中文：新增 OFL 授权的 Noto Sans SC；胶片及社交卡片在默认无衬线字体下遇到中文自动使用该字体，也可手动选择「思源黑体 · 中文」。不包含彩色 Emoji 字体或复杂文字塑形。
- 配方：新增独立 `FrameTemplate`，与摄影设置分别存储；切换类型保留内容、调色和滤镜，接入撤销重做、完整预设与相框预设。头像以受限 PNG 嵌入便携预设，导入时忽略外部路径。
- 内核：通过新增 `pe_frame_template` 与 C API 扩展，原有 ABI 结构保持不变。公共布局计算照片偏移和画布尺寸，整图与 JPEG 分条导出使用相同绘制路径，其他输入保留原有内存预算与整图处理限制。

当前范围是平台风格的静态照片卡片；没有连接平台账号，也不发布帖子。多图、九宫格、评论列表与任意拖拽不在本轮范围。重新使用时需重编译内核与应用，并完全退出旧应用；热重载不会更新动态库。
